# Тестирование StorePrice

## Команды

```bash
source scripts/android-env.sh
./gradlew testDebugUnitTest
./gradlew lintDebug
```

Отчёты:

- тесты: `app/build/reports/tests/testDebugUnitTest/index.html`
- lint: `app/build/reports/lint-results-debug.html`
- XML-результаты: `app/build/test-results/testDebugUnitTest/`

Один класс:

```bash
./gradlew testDebugUnitTest --tests 'com.storeprice.app.data.repository.RoomProductRepositoryTest'
```

Тесты Room и smoke-тест выполняются через Robolectric (`sdk = 34`), без устройства. База для CRUD-тестов — in-memory; для persistence-теста — файловая с удалением после теста.

## Что покрыто

- Создание товара с названием, ценой и необязательным штрихкодом.
- Обновление полей, рост `version`, сохранение `created_at`.
- Логическое удаление: товар исчезает из списка, карточки и поиска.
- Повторное использование штрихкода после удаления.
- Уникальность активного штрихкода без учёта регистра.
- Несколько товаров без штрихкода.
- Поиск по названию и штрихкоду, без учёта регистра и лишних пробелов.
- Приоритет: точный штрихкод → точное название → префиксы → вхождение.
- Стабильная сортировка.
- Литеральные `%` и `_` в поисковом запросе.
- Каталог из 5 000 товаров: вставка и поиск.
- Валидация пустого имени, пустой/отрицательной/дробной/слишком большой цены.
- Пустой штрихкод → `NULL`, ведущие нули сохраняются.
- Сохранение после перезапуска БД.

## Что не покрыто

- Ручной запуск на реальном Android-устройстве: телефон не подключён. Эмулятор Android 15 использован, но он не заменяет проверку камеры, экрана и реальной производительности.
- Compose UI-тесты кликов и навигации (есть только smoke-тест запуска).
- CameraX/ML Kit, разрешения камеры.
- Supabase, авторизация, RLS, Realtime.
- FCM, уведомления, переход из уведомления.
- Синхронизация, офлайн-восстановление, конфликты версий.
- Release-сборка и подпись.

## Ручная проверка на эмуляторе (выполнена)

Окружение: AVD `storeprice_test`, Pixel 4, Android 15 (API 35), x86_64; эмулятор 37.2.12, графика `swiftshader_indirect`, без окна. Финальный APK установлен через `adb install -r`, приложение запущено через `am start`.

Проверено вручную:

- холодный запуск и пустой каталог;
- добавление товара с ценой и штрихкодом `00123`, ведущие нули отображаются;
- после создания открывается карточка товара;
- дубликат активного штрихкода `00123` отклоняется с сообщением об ошибке;
- поиск по штрихкоду и по названию `MILK` без учёта регистра;
- открытие карточки, редактирование цены;
- удаление с подтверждением, товар исчезает из каталога;
- сохранение данных после перезапуска приложения и повторной установки APK.

Это проверка UI и навигации, а не замер производительности. Сохранение проверено кнопкой «Сохранить»; поведение аппаратного Enter и IME-действия на реальной клавиатуре телефона не проверялось.

## Ручная проверка на телефоне (не выполнена)

После подключения телефона:

```bash
adb devices -l
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.storeprice.app/.MainActivity
```

Сценарии для телефона:

1. Первый запуск: пустой каталог, кнопка «Добавить товар».
2. Добавить товар без штрихкода → появляется в списке.
3. Добавить товар со штрихкодом `00123` → ведущие нули отображаются.
4. Попробовать добавить второй товар с `00123` → ошибка дубликата.
5. Поиск `МОЛОКО`, затем с лишними пробелами → результаты корректны.
6. Поиск по части штрихкода → точное совпадение выше префикса.
7. Открыть карточку, изменить цену → список обновляется.
8. Удалить товар с подтверждением → исчезает из каталога и поиска.
9. Добавить товар с тем же штрихкодом после удаления → успешно.
10. Закрыть и снова открыть приложение → товары на месте.
11. Повернуть экран в форме → введённые данные не теряются.
12. Проверить тёмную тему и крупный системный шрифт.
13. Проверить ввод с экранной клавиатуры, включая действие «Готово».

## Производительность

Тест с 5 000 товаров подтверждает корректность выборки, но **не является замером скорости**. Точные показатели поиска и прокрутки нужно измерять на реальном устройстве; до этого нельзя утверждать, что требования по времени отклика выполнены.
