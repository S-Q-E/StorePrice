# StorePrice

Android-приложение для небольшого продуктового магазина: общий каталог товаров, цены в тенге, поиск, сканирование штрихкодов, история цен, офлайн-доступ и синхронизация между сотрудниками.

## Текущее состояние

**Этап 3 реализован и проверен на физическом телефоне.** Работает локальный каталог на Room и сканер CameraX + ML Kit: разрешение камеры, предпросмотр, распознавание распространённых форматов штрихкодов, поиск активного товара и переход к карточке или форме с заполненным кодом. Debug APK собирается, 50 тестов и lint проходят.

Экран сканера, запрос/отказ в разрешении, открытие камеры и её освобождение при выходе проверены на эмуляторе Android 15. Пользователь установил APK на телефон и подтвердил: штрихкоды распознаются, новые товары добавляются, повторное сканирование открывает карточку. Полная матрица форматов, автофокус, освещение и отзыв разрешения отдельно не проверялись.

Этап 4 начат: в `supabase/migrations/` подготовлены SQL-миграции с RLS, историей цен и серверными RPC; инструкция — [`docs/SUPABASE_SETUP.md`](docs/SUPABASE_SETUP.md). Миграции проверены локально, но не применены к живому Supabase. Вход по номеру телефона и паролю, синхронизация и FCM ещё не реализованы в Android.

Подробности: [`CURRENT_STATUS.md`](CURRENT_STATUS.md).

## Возможности

### Каталог

- каталог товаров с ценой в целых тенге;
- поиск по названию и штрихкоду без учёта регистра и лишних пробелов;
- приоритет точного штрихкода и точного названия;
- добавление и редактирование с валидацией;
- уникальность штрихкода среди активных товаров, ведущие нули сохраняются;
- удаление с подтверждением (логическое, с возможностью переиспользовать штрихкод);
- локальное хранение в Room, данные сохраняются после перезапуска;
- русский интерфейс на Compose Material 3.

### Сканер

- CameraX-предпросмотр и рамка наведения;
- ML Kit на устройстве: EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF, Codabar;
- запрос разрешения камеры, обработка отказа и отсутствия камеры;
- защита от повторной обработки одного кода за сессию;
- найденный активный товар открывает карточку;
- неизвестный код открывает форму нового товара с заполненным штрихкодом;
- камера останавливается при уходе с экрана.

## Стек

- Kotlin 2.0.21, Jetpack Compose, Material 3
- MVVM, Coroutines/Flow
- Room 2.6.1 + KSP, Navigation Compose
- CameraX 1.4.2, ML Kit Barcode Scanning 17.3.0 (встроенная модель)
- Gradle 8.9, AGP 8.7.3, JDK 17
- minSdk 26, targetSdk 35, compileSdk 35

## Быстрый старт

```bash
source scripts/android-env.sh
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённый телефон или эмулятор:

```bash
adb devices -l
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.storeprice.app/.MainActivity
```

## Ограничения

- На физическом телефоне подтверждён основной сценарий: распознавание, добавление товара и повторное открытие карточки. Не проверены отдельно все форматы на разных упаковках, автофокус, слабое освещение, блики, отзыв разрешения и отсутствие камеры; модель устройства не зафиксирована.
- Экран сканера и lifecycle камеры проверены на эмуляторе Android 15 (AVD `storeprice_test`); эмулятор не заменяет проверку реального распознавания.
- Нет instrumented/Compose UI-тестов: клики, разрешения и навигация проверены вручную.
- Серверная схема истории цен подготовлена, но UI истории и подключение Android к Supabase не реализованы. Синхронизация, Realtime и Firebase не начаты.
- Release-подпись и minify не настроены.
- Lint предупреждает о доступных новых версиях зависимостей; обновление не выполнялось, чтобы не менять проверенный toolchain без отдельной задачи.
