# Требования StorePrice

Полное техническое задание: [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md). Этот файл — краткая точка входа; при расхождении приоритет у полного ТЗ.

## Продукт

Android-приложение для продуктового магазина: совместный каталог товаров, цены в тенге, поиск по названию и штрихкоду, сканирование камерой, история цен, офлайн-просмотр, синхронизация между сотрудниками, роли и push-уведомления.

## Текущая граница работ: этап 0

Входит:

- проверка Linux, JDK, Android SDK, Gradle, ADB, Git;
- установка командного toolchain без Android Studio и без `sudo`;
- структура документации;
- минимальный нативный Android-проект на Kotlin + Jetpack Compose + Material 3;
- Gradle Wrapper, сборка debug APK, unit-тесты, lint;
- фиксация фактического результата.

Не входит (запрещено начинать без отдельного задания):

- база товаров и Room;
- CRUD, поиск, карточки товаров;
- сканер CameraX/ML Kit;
- Supabase, авторизация, RLS, Realtime;
- FCM и push-уведомления;
- импорт/экспорт, роли, история цен;
- выпуск подписанного release APK.

## Критерии приёмки этапа 0

1. `./gradlew assembleDebug` завершается успешно.
2. Файл `app/build/outputs/apk/debug/app-debug.apk` существует.
3. `./gradlew testDebugUnitTest` проходит; результаты тестов сохранены Gradle.
4. `./gradlew lintDebug` не содержит ошибок; предупреждения перечислены.
5. Документы `AGENTS.md`, `REQUIREMENTS.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `CURRENT_STATUS.md` созданы.
6. В `CURRENT_STATUS.md` указаны фактические версии, команды, ограничения и что осталось нереализованным.
7. Секреты и локальные пути не попадают в Git.

## Нефункциональные требования (для будущих этапов)

- Русский интерфейс, Material 3.
- Цены — целые тенге, без потери точности.
- Локальный каталог минимум на 5 000 товаров.
- Поиск не блокирует главный поток, результаты обновляются на каждый ввод.
- Офлайн: просмотр и поиск последней синхронизированной копии.
- Секреты сервера не попадают в APK.
- Все критические проверки прав и запись истории — на сервере.
- Воспроизводимая сборка через Gradle Wrapper.
